# Storyboard house style

Use this when you plan shots for a storyboard, an advert or a short film.

## Shot list format

Write each shot as one line:

`Shot N - <length in seconds>s - <framing> - <what we see> - <sound>`

Keep each shot between 3 and 6 seconds. A 30 second advert has 6 to 8 shots.

## Camera words

Use only these framings: wide, medium, close-up, extreme close-up, over-the-shoulder, top-down.
Use only these moves: static, slow push in, slow pull out, pan left, pan right, handheld.

## Look

- Warm late-afternoon light, soft shadows.
- Palette: teal, cream and burnt orange. No neon.
- Light film grain; 2.39:1 framing for films, 9:16 for social adverts.

Read `palette.md` (call `read_skill_file` with this skill's name and `palette.md`) for the exact colours.

## Prompt recipe

`<framing>, <subject and action>, <setting>, warm late-afternoon light, teal cream and burnt orange palette, light film grain`
