Branch `feat/chat-studio-tools`, worktree `.claude/worktrees/agent-af4d42af9fe33637a`, reviewed `c95112a..ccdfa1d` (read only, nothing edited or committed). Reviewed 2026-11-08.

**Verdict:** the gate is sound in its main path: approval is only the app-token decision route, plan ids are random and single-use, unlisted calls are declined, declined calls never execute, and the route tests drive the real gate (not mocked past it). No blocker. Four majors to fix before merge: duplicate call ids defeat per-item approval, the plan card hides arguments that change what gets made (input image paths, storyboard shot count, variations), "Always allow" cannot be turned off, and the chat model can cancel or list jobs that are not Chat's.

## Verified OK

- **Decision route:** it sits under `/api/`, so the middleware requires the app token through a constant-time compare. Agent tokens are not the app token, so they get a 401. Another browser origin is blocked by CORS, and a text/plain body does not parse into the model. If the user turns API auth off in Settings, any local process can decide plans, or send `studioAutoApprove: true` itself. That is the existing posture for every `/api` route.
- **Plan ids:** 40 random bits (uuid4), used once. A second or late decision gets a 404. Calls not listed in the decision are declined, and "edit" forces every call to deny.
- **Approval comes only from a click:** the model cannot approve through chat text. Text in a tool result can make the model call a render, but that render still gets a card.
- **Declined calls never execute:** `_declined_tool_call`. The model reads the declined text, and it is persisted.
- **Excluded tools are absent:** `speak_cloned`, `list_cloned_voices`, `upload_file`, `transcribe`, `recommend_models` and `storyboard_export_otio`. The project `export`/`import`/`delete`, `export_srt` and library `delete` actions are removed from the enums, unknown arguments are refused by `validate`, and the scope check happens after the schema check.
- **Storyboard import paths:** `storyboard_shot import` and `storyboard_audio add` paths go through `_agent_source` (output roots or upload handles only).
- **Results are trimmed:** no base64 and no download links, 1800 characters at most.
- **Streaming only:** `studioTools` is ignored by the non-streaming route.
- **Prefill watchdog:** the generating phase is sent before the plan. Keepalives keep the stream open, and the frontend timer resets on every chunk.
- **Hygiene:** no other products are named in the diff.
