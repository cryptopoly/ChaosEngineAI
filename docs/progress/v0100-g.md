# v0.10.0 package S-G: UX and UI review of the Storyboard flow

Branch `v0100/g`, cut from `release/v0.10.0` after the S-A to S-F merges. Plan: `docs/plans/v0.10.0-storyboard-polish.md`
(the review agent named at the end of "Packages for S8 to S15").

## How it was checked

Mac, 2026-11-16. Own backend on 8883 (`CHAOSENGINE_STORYBOARDS_DIR` in a private temp folder), vite on 8928, the
desktop app's browser pane at 1400 x 900 and 375 x 812. Real models: Iris-3B Turbo (drafts, redo still), Qwen-Image 2.1
sd.cpp (final pass), LTX-2.5 distilled q4 (redo clip, final clip), Qwen3.8-27B MLX 4-bit (Plan, Chat).

Journeys walked:
1. First run with no projects: the sample card, Open the sample.
2. Sample film: Play film (rough cut), edit shot 1's still prompt, Save, Redo still only (real Iris still), then
   Redo clip from the card (real LTX clip), Compare takes from the shot menu by keyboard.
3. Blank project, 480p: Plan from an idea, load the chat model in place, brief, 30 s, Propose shots (5 shots in 23 s),
   Use these 5 shots, Make them in Storyboard, Make drafts (5 Iris stills, about 1 min 30 s), Keep for final on
   shot 3, Final pass (Qwen still 7 min, then the LTX clip), Compare takes (draft against final), a caption in the
   Mixer, Export with SRT and Burn in (frame checked: caption burnt in, `.srt` beside the film).
4. Cast tab: a style from a shot still (palette read), the brand kit panel.
5. A 32-shot project made by script (copies of the sample's media; long project name, a long shot title, drafts,
   still-only shots, shots with no take, crossfades, kept shots): open time, requests, layout at both widths.
6. Keyboard only: project tabs (arrows), shot cards (Tab, arrows, Enter opens the editor, Escape), the shot menu
   (Enter, arrows), Compare takes (focus moves in, Escape returns focus to the menu button), the rough cut (Space, Escape).
7. Chat plan card for a storyboard render: tried, not seen (see "Not tested").

Automated checks on each project tab and dialog: text contrast against the composited background (WCAG AA, all text
in the dark theme), controls without an accessible name, horizontal overflow at 375 px.

## What changed (by fix)

1. `src/styles.css`: the two open rules restored from the S-E and S-F sides of the merge (a three-way merge of the
   file, conflict resolved as "both"; the diff against the broken file is exactly the lost lines). New test
   `src/__tests__/stylesheetBraces.test.ts`: every stylesheet under `src` closes each rule before the next top-level
   rule (fails on the broken file at line 15831).
2. `ProjectListTab.tsx`: the empty state keeps its sentence and the drop hint; its New project and Import bundle
   buttons are gone (the panel header has both). One primary in the list body: Open the sample.
3. `OverviewTab.tsx`: "Play film" (the rough-cut button, secondary) beside the next-step button once a clip exists.
4. `ShotCard.tsx`: the "New take" toggle moved into the shot menu, as "Make a new take next run" / "Cancel the new take",
   next to Compare takes, Redo clip only and Redo still only. The "New take next run" badge on the card stays and now
   carries the old toggle's tooltip. Card row: Lock, Keep for final, transition, menu, on one line (transition select
   compacted on the card). Keyboard R still marks the new take.
5. Stale card button: before "Keep", after "Keep as is" (`board.shot.keep`). Run bar hint: before "Mark shots with Keep
   to choose them for the final pass.", after "Mark shots with Keep for final to choose them for the final pass."
6. `RunBar.tsx`: with nothing to make, the bar shows the need line and "Make all unlocked" only; the drafts checkbox and
   "Make drafts" show only while something is missing; Final pass stays.
7. `ShotCard.tsx`: Keep for final shows once the shot has a take (or is already kept).
8. `PlanBrief.tsx`, `PlanTab.tsx`, `PlanProposal.tsx`, `plan.css`: Propose is secondary while a proposal waits or
   shots exist; "Make them in Storyboard" is primary; the proposal scrolls into view (instant under reduced motion) with
   focus on its heading; after Use, focus lands on "Make them in Storyboard".
9. `BatchBar.tsx`: "Making drafts" for a drafts run, "Final pass" for the final pass, "Making shots" otherwise.
10. `JobProgressLine.tsx` (shared with Chat), `chat.json` en: before "about {eta} left (from the clips made so far)",
    after "about {eta} left (timed on this machine)". The basis is measured takes of either kind, not only clips.
11. `FormatFields.tsx`: the hint passes the number only ("about 19 GB at peak").
12. `ShotCard.tsx`, `TakesStrip.tsx`: card thumbnail 512 px and takes-strip 128 px JPEG thumbs through the existing thumb
    route, fetched when near the screen (the `ProjectImage` lazy path). On reload of the 32-shot project, 8 card thumbs
    loaded for the visible rows.
13. to 15. `styles.css` (`.length-strip__part` min-width 0, overflow hidden; idle parts outlined), `StoryboardTab.tsx`
    (strip parts `tabIndex=-1`; the cards keep arrow keys), shot title input `title` attribute.
16. `ShotCard.tsx`: card `aria-label` "Shot 3 · Title" (or "Shot 3").
17. Shot menu: Edit prompts, Import footage, Compare takes, Make a new take next run, Redo clip only, Redo still only,
    Use still as reference, Move up, Move down, Delete.
18. `TakeCompare.tsx`: "No clip" for the clip facts of a take with no clip.
20. `styles.css`: reduced-motion guard for `.rough-cut__loading-bar span`.

New strings (en text, null in the other 10 locales): `board.shot.menu.markNewTake`, `board.shot.menu.unmarkNewTake`,
`board.batch.titleDraft`, `board.batch.titleFinal`, `board.compare.noClip`. Removed (no longer used):
`board.shot.newTake`. Changed en text: `board.shot.keep`, `board.passes.keepHint`, `studioChat.job.etaClips`.

Primary-action decisions (one per place):
- Projects, empty: Open the sample (New project stays in the panel header).
- Overview: the next step stays primary; Play film is secondary.
- Shot card: Keep for final is the one pass action; every remake (new take, redo clip, redo still) and Compare are in the menu.
- Run bar: Make N missing while something is missing; nothing primary when every shot is made.
- Plan: Propose shots, then Use these N shots, then Make them in Storyboard.

## Not fixed, and why

- 21 (Tab through every card): the fix is a roving model inside the card (inner controls `tabIndex=-1` until the card is
  entered with Enter or F2, Escape back to the card). Enter already opens the shot editor, so the key map needs a
  decision and the E2E keyboard checks need rewriting; too wide for a polish pass on shared files with agents H and I
  working. Suggest an FU row.
- 22 and 23 (which pass is primary on a fresh planned film, and what Make drafts means once drafts exist): product
  choices for the owner. Recommendation: on a project with no takes, make "Make drafts" the primary and "Make N missing"
  secondary; once every shot has a draft still, hide Make drafts (or label it "Redo drafts") so "Make N missing" (the
  clips) is the next step.
- 24, 25, 28, 29: app-wide surfaces (chat library classification, app shell at phone width, the run label, global
  button focus ring), outside the Storyboard files.
- 26: Export tab wording; agent H is changing that tab now.
