## Defects found and fixed

- The suggestion's "Use 30 s" lost the click when it came straight after typing the brief. The brief saves on blur, the tab goes busy, and the button turned disabled between mousedown and click. The button no longer disables, because the op queue orders it after the brief. The Length chips have the same pre-existing race. They were not changed (see below).
- Spec 05 was stale: it expected five project tabs, and "Optional." now matches two lines.

## Open, for the owner or a later package

- Drafts use the project's own still model at half size. With Qwen saved, "Make drafts" is still about 6 min per still (180 min for 30 shots), so drafts help less than the item suggests. The fast-model button is the real fix there. A choice for later: should drafts always use the fastest installed model?
- The Overview "next step" card still says "Make 30 missing" as its primary on a slow fresh film. Item 3 covers only the run bar.
- The Length chips go disabled while busy, so a chip clicked straight after typing in the brief can drop the click (the same race as above). Not changed.
- The suggestion reads lengths and kinds in English words only. Digits with "s" / "min" work in any brief.
- The Escape key to return from a control to its card was not added (Shift+Tab does it), so it does not fight the menu's and the title field's own Escape.
