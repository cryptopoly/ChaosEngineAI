# v0.10.0 package S-M2: long projects, the UI half (item 8)

Branch `v0100/m2`, from `release/v0.10.0` with S-K and S-M1 merged. Plan: `docs/plans/v0.10.0-eight-improvements.md`,
package S-M2. Built on the S-M1 contract in `docs/progress/v0100-m1.md`. Not merged.

## What changed

### Pause and resume in the batch bar
- `BatchBar.tsx`: a Pause button while a batch runs; after a click it reads "Pausing after this step…" until the
  batch stops. New `PausedBatchBar.tsx` (and `pause.css`): "Paused", the reason ("Paused when the app closed; Resume
  carries on." for a restart, or after a finished step for a user pause), "{done} of {total} steps done, {n} left",
  "about {time} left" when the backend gives `etaSeconds`, Resume (primary) and Cancel batch.
- `useStoryboard.ts`: the latest batch is shown when it is `paused` (not only running); `pauseBatch`, `resumeBatch`,
  `pausing`; a paused batch's bar data is read once (it is not polled); Cancel of a paused batch reloads. New `call`
  runs a project route that returns the project (attach song, lyric captions) in the op queue, adopting a stale
  revision like an op and handing any other error back to the caller. `isBatchPaused` in `storyboardLogic.ts`.
  `RunBar.tsx` shows the paused bar; `StoryboardTab.tsx` passes the handlers.

### Song panel (`song/`, on the Plan tab under the brief)
- `SongAttach.tsx`: a track from the Music library (listed with its length) or an audio file path (typed or the
  desktop file dialog, the existing `PathField`).
- `SongPanel.tsx`: title, length, BPM and section count; `SongRuler.tsx` (sections as wide as their share, shaded by
  energy, labels are buttons that turn into a field; Enter saves with `edit_song`, Escape keeps the old label); the
  rough-analysis note; Change song, Remove (`clear_song`).
- "Make a cut plan" → `CutPlanReview.tsx`: shots grouped by section with lengths and kept prompts, the cap and where it
  came from (video model, request, or default 4 s), the backend's note; "Use these N shots" applies `apply_plan`
  replace (one Undo), with a confirm when shots with takes would leave, and Replace off while a shot is locked.
- `SongLyrics.tsx`: one caption line per line, saved with `edit_song` on blur; Timing Automatic / From the sections /
  By ear (off when `GET /api/storyboard/lyrics/speech` says not ready, with its reason in plain words); the route's
  `notes` are shown; any refusal (409 `no-stt`, 400) is shown in its own words. Without a mixer clip it says so.
- `songLogic.ts`: clock, ruler parts, relabel, lyrics lines, cut plan grouping.

### Freestyle board (`board/`, a new Board tab between Storyboard and Mixer)
- Tab id `freestyle` (label "Board"), because old stored routes may hold the retired id `board`.
- Cards: every shot (active take's still, its film number) and every character, place and style (first picture,
  dashed border). Free layout on a dotted plane; pan (wheel, drag on empty board, one finger), zoom (Ctrl/Cmd wheel,
  trackpad pinch, two-finger pinch, the − / + buttons, Fit); drag to place (moves every selected card); multi-select
  with Shift/Cmd/Ctrl or the "Select several" switch for touch.
- "Order these N" (two or more shots selected: only those swap, inside the slots they hold) or "Order all shots":
  reading order left to right then top to bottom, one `reorder` op, Undo puts it back.
- Pictures dropped on the board, or "Add pictures": a dialog asks new shots (default) or characters / places / a
  style. New shots use a new op `board_add_shot` (shot + still take + position in one Undo); references use
  `add_reference`.
- Side column: the chat model bar; one shot selected → its card chat (the Plan tab's Rework flow, see below); a
  reference → its name and "Edit in Cast"; otherwise the board chat = the project's direction chat (`PlanDirection`).
- Song sections as a compact ruler along the bottom of the canvas when a song is attached.
- Keyboard: one roving tab stop; arrows move the focus to the nearest card that way; Space adds or removes a card,
  Enter selects only it; arrows move the selected cards by 8 px, Shift+arrows by 64 px (saved 0.5 s after the last
  press, one op); Home / End; Cmd/Ctrl+A; Escape clears the selection. Card names "Shot 3 · Title" / "Character ·
  Mara", `aria-pressed` for selection. Reduced motion: no card transition.
- Files: `BoardTab`, `BoardCanvas`, `BoardCard`, `BoardToolbar`, `BoardSide`, `BoardCardChat`, `BoardAddPictures`,
  `boardLogic.ts`, `useBoardView.ts`, `useBoardPositions.ts`, `useBoardInput.ts`, `board.css`.
- Rework reuse: the shot rework chat was moved out of `PlanShotRow.tsx` into `useRework.ts` (state) and
  `PlanReworkChat.tsx` (view); the Plan tab behaves as before and the board uses the same two.

### Backend (small model change)
- `models.py`: `Project.board` (`Board.pos: {id: {x, y}}`, coordinates within ±100000, default empty), `"board"` added
  to the store's diffed `_TOP_KEYS` so Undo / Redo cover it. Old projects load unchanged.
- `board_ops.py` (registered in `ops.py` like `song_ops`): `place_cards {positions}` (unknown ids refused, stale
  positions dropped on the next move, revision checked) and `board_add_shot {still, title?, index?, x?, y?}` (picture
  file arg through the ordinary staging). TS: `StoryboardBoard`, op args in `src/types/storyboard.ts`.
- The first move on a board also saves the grid places of the cards not placed yet, so a later reorder (which changes
  grid places) does not move cards around the ones the user placed.

10 locales. `npm run i18n:validate` OK.

## Defects found and fixed here
- After "Order all", cards never moved by hand jumped to new grid places (grid places follow film order): the first
  save now freezes every unplaced card where it shows.
- "Time the lyrics" lost its click straight after typing (the lyrics save on blur made the button disabled between
  mousedown and click, the S-K race): it no longer disables on the project's busy state; the op queue orders it.
- A fast arrow press after Home went to the old card (focus moved on the next frame): focus now moves at once.
- Dropped pictures landed with their corner at the pointer; now centred.
- Speech-to-text reason showed twice after timing.
