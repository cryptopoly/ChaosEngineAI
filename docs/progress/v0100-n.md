## Suggestions (ranked, with cost)

1. Keep unsaved field text when its save is refused (conflict or backend down): hold the draft per field, show it
   with "Your text was not saved: put it back" after adopting the latest. Fixes defect 14 for every blur-save field.
   Cost: 1 day (a small hook used by the 17 fields, tests).
2. Roving tab stops on the Plan tab's shot rows, like the Storyboard list: 5 stops per shot today (95 for 19 shots,
   300 for 60). Cost: half a day (reuse `useCardTabStops`).
3. When a song is attached and longer than the film, say it next to Time the lyrics and offer the cut plan there
   (today the note comes only after timing). Cost: 2 hours.
4. The Length chip and an attached song disagree silently (15 s chosen, 64 s song). Offer "Use the song's length".
   Cost: 2 hours.
5. Show the draft model in the Make drafts tooltip on the Overview card too, and the time per draft. Cost: 1 hour.
6. Stop the Mixer's preview probe when the project has never rendered (defect 15). Cost: 1 hour.
7. A light theme (tokens exist for dark only). Cost: several days; a design decision first.
8. The E2E suite's CLI calls send no token: on a backend with `requireApiAuth` on (the default for a new HOME) every
   CLI check fails with 401. Let `chaosengine-cli` read the loopback session token like the MCP relay. Cost: 2 hours.
