# v0.10.0 R6: FU-154 cloning form (branch v0100/r6)

## Done
- New voice form: radio group "Cloning model" (`CloneModelPicker.tsx`) listing every downloaded, runnable cloning model by name with download size and the measured cost (same chip text as Speak). The backend's default is preselected and carries a plain "Default" tag; one downloaded model is shown selected; none downloaded shows "No cloning model is downloaded yet." with a Download button (polls until done). Save needs a selected model, so it stays off when none is downloaded.
- Backend: `POST /api/voice/clone/voices` takes `model`. Empty means the default (the default if downloaded, else any downloaded one; never a 422). An unknown key is a 400. The key is saved on the voice record (`model`) and returned by the voices routes.
- Speak and read-aloud: with no model named, `clone_plan` uses the voice's recorded model while it is still downloaded, else the default. `voice_speak.list_voices` reports each clone voice's own model, so the Speak screen preselects it. Old voices (no `model`) behave as before.
- Strings: `voice.clone.modelTitle/modelNone/modelDownload/modelDefault/modelSize` in `studio.json` (en filled, ten others null).

## Default chosen: `DEFAULT_CLONE_MODEL = "qwen3-tts-1.7b"` (was 0.6b)
One constant in `backend_service/catalog/voice_models.py`; the rows' `default` flag, the form's tag and `pick_clone_model("")` all follow it.
Measured on this Mac (Apple M4 Max 64 GB, catalog `estimates`):

| row | s per 10 s speech | peak GB | download GB | languages | catalog note |
|---|---|---|---|---|---|
| qwen3-tts-1.7b | 3.6 | 6.5 | 4.54 | 10 | "Closer likeness", about as quick as 0.6B |
| qwen3-tts-0.6b | 3.2 | 4.3 | 2.52 | 10 | "Good likeness from 10 to 20 s" |
| voxcpm2 | 5.2 | 3.8 | 3.23 | 30 | 48 kHz; no likeness claim |
| chatterbox-mtl | 3.6 | 3.7 | 3.2 | 23 | Expression dial |
| chatterbox-turbo | 2.1 | 1.7 | 1.2 | English only | fastest, needs 5 s sample |

Reasoning: clone likeness matters most; 1.7B is the catalog's likeness model and costs 0.4 s per 10 s (12 percent) and 2.2 GB peak more than 0.6B, easy on 64 GB. VoxCPM2 is 45 percent slower than the 1.7B and no row has a listening rank yet (`rank` is empty; the owner's check, D-70), so none beats the Qwen pair on evidence. On the 4090 the twin is 5.3 GB peak (fits 24 GB); a GPU too small for it falls to any downloaded runnable model through `pick_clone_model` and `pickCloneModel`. Side effect to know: old voices without a recorded model now speak with the 1.7B when downloaded (was 0.6B). To change the default, edit the one constant.
