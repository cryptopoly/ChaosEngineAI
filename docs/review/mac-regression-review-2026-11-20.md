# Mac and Linux regression review of the Windows / CUDA pass (2026-11-20)

**Scope.** `git diff origin/release/v0.10.0...test/rtx4090` (merge base `b5d99d68`, the release tip; 77 commits,
394 files). Every shared code path the task named was read as it runs on macOS (Apple Silicon, `sys.platform ==
"darwin"`, no CUDA, no `nvidia-smi`) and on Linux x86_64 with and without NVIDIA. `inference/llama_cpp_engine.py`,
`state/openai_compat.py`, `mlx_worker_request.py` and `helpers/hf_cache_paths.py`'s older parts are **not changed in
this range** (their Windows changes were already on the release branch), so they were not re-reviewed.

**Method.** Code reading; a platform simulation (`platform.system` / `platform.machine` / `sys.platform` /
`shutil.which("nvidia-smi")` patched) run against this branch and against an export of `release/v0.10.0`; a field-by-field
catalog diff between the two (267 rows before, 284 after); `scripts/audit-catalog-repos.py` (passes: 221 repos, 281
references); the tests listed at the end.
